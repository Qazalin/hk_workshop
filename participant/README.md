# Workshop

Work on the challenge file announced by the organizer.
Make `def solve` in the challenge file faster, preserving the result and leaving the inputs unchanged.

1. Edit `N.py`.
2. Check: `python workshop.py check N.py`
3. Submit: `python workshop.py submit N.py --name YOUR_NAME`

To inspect the computation: `VIZ=1 python workshop.py check N.py`.
You can improve and resubmit. Your best passing score counts.
